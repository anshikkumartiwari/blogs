# Blogs Content Repository

This repository serves as the content store for [anshikkumartiwari.github.io](https://anshikkumartiwari.github.io).

## Structure
Each blog has its own folder containing `blog.md` and any associated assets or images:

```text
blogs/
├── manifest.json
├── blog1/
│   ├── blog.md
│   └── (images/assets)
├── blog2/
│   ├── blog.md
│   └── (images/assets)
└── blog3/
    ├── blog.md
    └── (images/assets)
```

## Adding a New Post
1. Create a new folder (e.g., `blog4/`).
2. Add `blog.md` with YAML frontmatter.
3. Register the new post in `manifest.json`.
